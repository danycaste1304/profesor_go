# Profesores reales del juego

Esta ficha recoge los datos entregados para adaptar los diez profesores de la
feria. La colección demo ya no contiene personajes de ejemplo.

- Nombre de carta: **Prof. Henry**; nombre completo: **Henry Carvajal**.
- Rareza: **común**. Tarjeta demo: `DEMO-TAG-01`.

  suave, traje azul marino, camisa blanca, corbata azul y brazos cruzados.
